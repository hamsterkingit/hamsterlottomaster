# 🦁 사파리 로또 번호 추천 서비스

사파리 컨셉의 로또 번호 추천 웹 서비스입니다.

## 기능

- 🎲 랜덤 로또 번호 생성 (1-45 중 6개 + 보너스 번호)
- 📸 생성 기록 저장 (최대 10개)
- 🎨 사파리 테마 디자인
- 📱 반응형 디자인 지원

## 사용 방법

1. `index.html` 파일을 웹 브라우저에서 엽니다
2. "🔍 번호 탐색하기" 버튼을 클릭합니다
3. 생성된 번호를 확인합니다
4. 스페이스바를 눌러 빠르게 번호를 생성할 수 있습니다

## 파일 구조

- `index.html` - 메인 HTML 파일
- `style.css` - 스타일시트
- `script.js` - 로또 번호 생성 로직

## 라이선스

이 서비스는 참고용이며, 실제 당첨을 보장하지 않습니다.
